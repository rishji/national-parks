# National Parks

A colorful, map-first tracker of my bucket-list goal: visiting all 63 U.S. national parks. Click any park for
consistent facts (size, visitors, highlights, best season, getting there) and, for parks I've visited, my trips.

Live at **https://parks.rishimohnot.com** · Vite + React + TypeScript · deployed on Cloudflare Pages from `main`.

To add a visit or photos, see [AGENTS.md](AGENTS.md#adding-a-visit). Park facts come from NPS and Wikipedia;
hero photos are public-domain U.S. government images from Wikimedia Commons.

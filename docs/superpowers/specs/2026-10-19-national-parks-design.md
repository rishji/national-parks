# National Parks Tracker — Design

**Date:** 2026-10-19
**Site:** `parks.rishimohnot.com`
**Repo:** `~/Projects/national-parks` → `github.com/rishji/national-parks`
**Design mockup:** https://claude.ai/artifact/8wKFZrc4sL7CP9bn3pCsPf

## Goal

A public, visually bold page tracking Rishi's bucket-list goal of visiting all 63 U.S. national parks. A map
shows every park with its own art; clicking a park shows consistent facts about it, and — for parks Rishi has
visited — his visits (dates, companions, photos). It is deliberately more colorful than the muted main site
(`rishimohnot.com`).

**Success:** the page loads fast, reads clearly at a glance (what's visited, where every park is), feels like a
vintage park poster in full color, and adding a visit is a one-file edit plus a push.

### What Rishi specified vs. assumptions

- Specified: map of all parks with per-park art and names (overflow names on hover); click → consistent park
  info; visited parks show visit info (dates, companions, a few photos) **at the top of the panel**; state names
  and borders shown, light; progress header; visited/unvisited styling + filter; visit timeline; grid view;
  custom per-park art, AI-generated by Rishi later, with landscape-icon placeholders until then; park
  boundaries drawn on the map; stronger leader lines in crowded areas; repo-file data entry; subdomain
  `parks.rishimohnot.com`.
- Assumed: 63 official national parks; Cloudflare Pages hosting like `where-ive-been`; light mode only; companion
  names written as Rishi enters them (first names suggested — the site is public).

## Non-goals (v1)

- No backend, CMS, auth, or admin UI. No live NPS API calls.
- No automated visit discovery. (Phase 2, separate spec: infer visit dates by intersecting
  `where-ive-been` / `location-history` data with park boundaries, and pull photos from Google Photos via
  computer use. The visits file format below is designed so that phase only appends entries.)
- No per-park static pages / SEO pages (can be added later).

## Architecture

**Stack:** Vite + React 18 + TypeScript, no CSS framework, no router (hash-based selection). Static build
deployed to Cloudflare Pages. Map rendered as hand-built SVG with `d3-geo`; pan/zoom with `d3-zoom`.

```
national-parks/
  src/
    data/parks.json        # generated + validated facts for all 63 parks (committed; never hand-edited in normal use)
    data/boundaries.json   # simplified, pre-projected park footprints (TopoJSON, generated)
    data/visits.ts         # THE file Rishi edits
    data/types.ts          # Park, Visit, PartialDate types
    lib/                   # pure logic: stats, date formatting, callout layout, filtering
    components/            # Header, MapView, ParkBadge, ParkPanel, VisitCard, PhotoViewer, GridView, Timeline
    styles/                # tokens.css (palette, type), global.css
  public/
    art/<id>.webp          # custom art (optional per park)
    icons/<kind>.svg       # 17 placeholder landscape icons
    hero/<id>.jpg          # public-domain NPS hero photos
  photos/<park>/           # web-sized, EXIF-stripped visit photos (committed)
  scripts/
    build-parks.mjs        # compile + validate parks.json from sources
    build-geo.mjs          # states + park boundaries → projected, simplified TopoJSON
    photos-add.mjs         # resize + strip EXIF + register in visits.ts
    art-add.mjs            # convert generated art → public/art/<id>.webp
  docs/art-prompts.md      # shared style prompt + per-park subject lines
```

## Data model

### `parks.json` (facts)

```ts
type Park = {
  id: string;               // "zion"
  name: string;             // "Zion" (footnote marks stripped)
  lat: number; lon: number;
  states: string[];         // stored for stats ("states covered"); not displayed in the panel
  established: string;      // ISO date "1919-11-19"
  acres: number;
  visitors: number; visitorsYear: number;   // latest available year
  sizeRank: number;         // 1 = largest of 63 (computed)
  visitorRank: number;      // 1 = most visited (computed)
  description: string;      // 2–3 sentences, own words
  highlights: string[];     // 3–4 signature sights/hikes
  bestSeason: string;       // "Apr–May, Sep–Oct"
  nearestAirport: string;   // "Las Vegas (LAS) · ~2.5 hr"
  npsUrl: string;
  kind: IconKind;           // placeholder icon: one of 17 landscape kinds
  heroPhoto: { src: string; credit: string; sourceUrl: string };
  sources: string[];        // where facts were checked
};
```

**Sourcing and validation.** Seeded from Rishi's sheet ("National Parks", Google Sheets) which has name, coords,
established date, size, 2022 visitors, description. Every field is then validated and completed against public
sources: NPS (nps.gov park pages, NPS Visitor Use Statistics for latest visitor counts, NPS Land Resource Division
boundaries), Wikipedia's list of national parks, and Earth Trekkers (earthtrekkers.com) for highlights, best
season and travel logistics. Text is written in our own words — no copying of copyrighted text or images.
Discrepancies between sources are resolved in favor of NPS and noted in `sources`.

### `visits.ts` (the only file edited routinely)

```ts
type PartialDate = `${number}` | `${number}-${number}` | `${number}-${number}-${number}`; // "2021" | "2021-05" | "2021-05-28"
type Visit = {
  park: string;          // Park.id
  start?: PartialDate;   // omitted → shown as "Date TBD"
  end?: PartialDate;
  with?: string[];
  note?: string;
  photos?: string[];     // filenames under photos/<park>/
};
```

Seeded with the 14 parks marked visited in the sheet, undated: Badlands, Bryce Canyon, Carlsbad Caverns,
Congaree, Death Valley, Grand Canyon, Grand Teton, Guadalupe Mountains, Hawaiʻi Volcanoes, New River Gorge,
Pinnacles, Yellowstone, Yosemite, Zion. A park is "visited" iff it has ≥1 visit. Multiple visits per park allowed.

## Map

- **Base:** custom SVG. Lower 48 in Albers USA; Alaska and Hawaiʻi in their conventional insets; American Samoa
  and U.S. Virgin Islands in labeled framed insets in the open Atlantic (east of the Carolinas) so they never
  cover Florida's parks. Ocean deep teal with faint wave pattern; land warm sand with grain texture; nation
  outline in ink with an offset shadow.
- **States:** borders as light dashed lines; names in light, letter-spaced small caps at each state's visual
  center, abbreviated for small northeastern states; rendered beneath parks.
- **Park footprints:** each park's actual NPS boundary, simplified and pre-projected at build time, drawn as a
  soft pine-green fill with an ink outline. Parks too small to see get a minimum-size marker. Hovering a badge
  highlights its footprint in gold and vice-versa.
- **Badges:** circular art (custom art if present, else the placeholder icon for its `kind`), cream ring.
  Visited: full color, gold ring, gold check, drop shadow, name tag always shown. Unvisited: desaturated and
  slightly faded; name on hover/focus. Hover/focus/selected: scale up, name tag inverted.
- **Callout layout (crowded areas):** parks whose badges would overlap at the current zoom are grouped into
  clusters. Clustered badges are fanned out into open space around the cluster with even spacing; each connects
  to an anchor dot on its footprint by an angled (elbow) leader line in ink, laid out so lines don't cross.
  Uncrowded badges sit directly on their footprint with no line. Layout is recomputed per zoom level: as you zoom
  in and space opens up, badges animate back onto their footprints and leaders fade. Badge and label size stay
  constant on screen while zooming.
- **Zoom/pan:** wheel, pinch, drag, +/− buttons, reset. Bounded zoom range.
- **Interaction:** click/Enter on a badge (or footprint) selects the park → URL `#<id>` → panel opens.
  Back/Escape closes. All badges are real buttons in tab order with accessible names ("Zion, visited").
- **Filter:** All / Visited / Not yet — non-matching badges and footprints fade, not removed.

## Park panel

Desktop: right-side panel (~420px) sliding in over the map. Mobile: bottom sheet. Prev/next arrows (alphabetical)
and close.

Order for a **visited** park:
1. Header — large art, name, "National Park · Est. YEAR", gold "Visited" stamp.
2. **Your visits** — one card per visit, newest first (undated last): date range or "Date TBD", companion chips,
   note, photo thumbnails → full-screen viewer (arrows/swipe/Escape).
3. Hero photo with credit.
4. Description.
5. Highlights (chips).
6. Stat tiles: size + size rank, visitors + visitor rank, established, best season.
7. Getting there: nearest airport + drive time, NPS link.

For an **unvisited** park: same, minus section 2, with a "Not yet" stamp. State is not shown (the map makes it
obvious).

## Page

- **Header:** sunset gradient band (dusk violet → pink → orange → gold) with layered mountain silhouettes into
  the page. Title, short intro, huge "14 / 63" count, trail-style progress bar with hiker marker and summit flag,
  stats: states & territories covered (of 32 that contain parks — exact figure recomputed from validated
  data), acres explored, most recent visit (or "Date TBD").
- **Controls:** filter segmented control; Map | Grid toggle; legend.
- **Map view** (default) and **Grid view**: grid of art cards (visited cards full color with orange offset
  shadow; unvisited muted), sortable by name, visit date, region, size. Grid is the primary mobile browse.
- **Timeline:** "The trail so far" — horizontal strip of visits in chronological order; undated visits grouped
  under "Date TBD" at the end. Click → selects park.

## Visual direction ("golden-hour poster")

- **Palette:** Paper `#F6EEDC`, Ink `#1E2A2F`, Ocean `#0F4C5C`, Sunset `#F26B38`, Canyon `#C8402E`,
  Pine `#1F5A3D`, Sky `#7FC8D9`, Gold `#F2B33D`, Blush `#F29C8F`, Dusk `#6B4E8C`. Small text never uses
  Sunset/Gold on Paper (contrast); accent text uses `#A8321F`.
- **Type:** Zilla Slab (display, routed-wood-sign feel), Figtree (body/UI). Google Fonts.
- **Shapes:** 2px ink outlines, hard offset shadows (poster print feel), pill chips, rounded cards.
- **Motion:** staggered badge pop-in, spring panel, hover lift; all disabled under `prefers-reduced-motion`.
- **Light mode only.**
- **Placeholder icons:** 17 flat landscape scenes (mountain, volcano, lake, canyon, arch, cave, forest, big
  trees, glacier, dunes, coast, swamp, geyser, island, desert, waterfall, hoodoos), each park assigned one.

## Art

Rishi generates custom art per park with an AI image model. `docs/art-prompts.md` provides one shared style
prompt ("flat vintage WPA screen-print, limited 5–6 color palette drawn from the site palette, bold shapes, no
text, centered subject, composed for a circular crop") plus a per-park subject line (e.g. Zion: "Angels Landing
at sunset above the Virgin River"). `scripts/art-add.mjs <id> <file>` converts to a square 512px webp in
`public/art/`. Missing art falls back to the placeholder icon — the site is always complete.

## Photos

`npm run photos:add -- <park> <visit-index> <files…>`: resizes to max 2400px, strips all EXIF (incl. GPS),
writes to `photos/<park>/`, appends filenames to that visit in `visits.ts`. Build generates responsive sizes via
`vite-imagetools`. Originals stay in Google Photos; repo holds only web-sized copies.

## Deploy

GitHub repo `rishji/national-parks`; Cloudflare Pages project with Git integration (push `main` → production,
branches → previews), mirroring `where-ive-been`. Custom domain `parks.rishimohnot.com` added to the
`rishimohnot.com` zone — a production DNS change, confirmed with Rishi before applying. CI (GitHub Actions)
runs typecheck + tests + build.

## Error handling

- Missing art → placeholder icon. Missing hero photo → sunset gradient with icon. Missing photo file → build
  fails (caught by tests), never a broken image in production.
- Unknown `#hash` → ignored, map shown. Invalid partial date in `visits.ts` → type error at build.

## Testing

Vitest:
- **Data:** exactly 63 parks; unique ids; every park has all required fields, a footprint, a valid `kind`, a hero
  photo file; ranks are a permutation of 1–63; every visit references a real park; every listed photo exists;
  partial dates parse and `end ≥ start`.
- **Logic:** stats (count, states, acres, latest visit), date formatting, visit sorting (newest first, undated
  last), filter.
- **Callout layout:** at the default zoom and at a viewport of 1280px and 390px, no two badges overlap, no two
  leader lines cross, all badges within the frame.
- **Manual verification:** check the deployed site in Chrome at desktop and phone widths (map, panel, grid,
  timeline, keyboard nav) before calling it done.

## Phase 2 (separate spec, later)

Visit discovery: intersect location history (`where-ive-been`, `location-history`) with park footprints to
